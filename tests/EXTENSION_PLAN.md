# 六模块扩展验收设计

以下为待执行计划，不是通过报告。保留现有66项基线；全部使用独立临时SQLite与专用HTTP端口。

- 住宿：可用床位→申请/分配→本人查看→退宿；同库双进程抢最后床位最多一人成功；重复提交不重复占用；退宿只释放一次；他人不可读改。
- 请假：日期区间校验、重叠申请拒绝、审批、销假；不合法/反向日期与终态跳转拒绝；普通人不能审批；本人隔离和幂等。
- 包裹：运营入库→本人获取随机领取凭证→运营核销；凭证仅本人可读，后台/他人列表与动作不泄露；未满足状态或错凭证拒绝；重复领取失败。
- 设备：目录→申请→出借→归还；同库双进程最后库存竞争最多一人；重复归还不增加库存；本人归属、运营动作、服务端库存校验。
- 招聘：岗位浏览→投递→撤回/人工处理；重复投递、关闭岗位、终态/非法动作拒绝；本人投递材料不在他人/公开列表泄露。
- 问卷：公开结构→本人作答→匿名汇总；每人仅一次、重复幂等不重复计数；非法题/选项拒绝；汇总不得泄露用户标识、个人答卷、session或凭证；本人提交结果适当隔离。
- 通用：停用应用后猜测模块API拒绝；创建幂等同内容原结果、不同内容409；普通账号后台拒绝；模拟及生产边界清晰；所有测试只记录实际执行结果。
