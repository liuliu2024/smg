# 八模块扩展验收设计

基线：保留现有49个Node测试项。以下为待实现契约确认后的测试计划，不代表已通过。

| 模块 | 完整流 | 权限及非法输入 | 并发与撤销 |
|---|---|---|---|
| 校园报修 | 本人报修→运营受理→处理→完成 | 他人详情/修改不可访问；普通人运营动作拒绝；非法状态拒绝 | 同幂等键不重复建单；取消不能重复操作 |
| 场地预约 | 查询场地→预约有效时间段→审批/取消 | 本人隔离、过期/反向时间段拒绝 | 同场地重叠时间段并发最多一单；取消释放后可重新预约 |
| 失物招领 | 发布→审核→公开→认领/关闭 | 未审核不公开；公共结果不含用户标识/联系方式/session；他人不能关闭 | 重复状态操作拒绝 |
| 活动报名 | 活动查询→报名→本人取消 | 不可报名关闭/过期活动；他人报名记录不可见 | 最后名额并发仅一人；重复报名不占位；取消只恢复一次 |
| 意见反馈 | 提交→运营回复→本人查询 | 他人不可看反馈正文或操作；普通人不能运营回复 | 幂等不重复创建 |
| 证明申请 | 提交→审核→领取/拒绝 | 本人详情隔离；普通人审批拒绝 | 非法状态跳转/重复审批拒绝 |
| 二手发布 | 发布→审核上架→下架/售出 | 未审核不公开；公共信息脱敏；他人不可修改 | 终态不得重复转移 |
| 办事审批 | 申请→运营审核→通过/拒绝→本人查询 | 角色运营动作受限；本人隔离；审批意见校验 | 幂等、非法状态与重复审批拒绝 |

模块列表和全局搜索补充：分类匹配、关键词匹配、PLANNED不伪装ACTIVE、未公开/越权数据不入搜索、各新模块真实内部路由。

所有测试使用独立临时SQLite数据库与独立端口；并发检查至少真实HTTP并发，关键库存/容量进一步用两服务进程同库。报告只记录真实执行结果。
