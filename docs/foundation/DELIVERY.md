# Foundation 1.0 交付与验收

本次按照 v5.0 技术合同实现校园服务底座的可运行 DEMO，并采用 v4.2 的接入、权限、发布和运行处置要求。附件 001 SQL 原样纳入迁移，当前工作区中与原件 SHA-256 一致。后续迁移补充学校、环境、实例和发布的组合约束。新底座使用专用 PostgreSQL，原校园门户的数据和流程继续保留。

| 切片 | 已验证的交付 |
|---|---|
| D01 工程落点 | 保留现有 Node 24、Next 16 和 npm 工程。新入口 /foundation 与版本化 API 门面 /api/v1/foundation。技术映射、部署命令和依赖边界见 IMPLEMENTATION.md。 |
| D02–D04 数据、身份、目录 | PostgreSQL 16.15 空库迁移、checksum 和幂等种子。两校七岗、会话/CSRF、即时撤权、范围目录、独立回调密钥和连接绑定。共享配置写入限校级授权。 |
| D05 接入与发布 | 接入阶段材料、角色审核与历史。固定定义、依赖摘要和测试代次，独立审批后激活。暂停业务保留到显式恢复。历史版本可发起回退草稿并重新测试、审批。 |
| D06–D07 队列与执行 | 有限 DSL、实例、任务、计时、事件订阅。PostgreSQL 领取与租约恢复，运行时复查授权。未知操作按原记录查询，核查允许领案、追加证据和记录待现场处置。人工意见不直接改写供应商事实。 |
| D08 三个样板 | 图书预约到馆员待取，丢失响应后查证原预约。充电开始/停止以权威事件推进，证据满足时出具模拟账单。柜门打开与包裹交接各有记录。 |
| D09 桌面与移动 | 1440 与 390 尺寸实测。已点通图书办理、跨岗位发布、接入调研审核、模拟充电和开柜未取件。回退和案件新增表单已做语法检查及后端验收，页面点击复验待执行。 |
| D10 复用与交付 | 两校共用相同发布模板和适配器版本，数据、身份和凭证独立。附 OpenAPI、迁移、种子、运行说明、集成用例和 CI。 |

## 实际检查

- PostgreSQL 16.15 上运行全量 Node 测试，133 项通过，零失败、零跳过。其中旧门户 104 项，Foundation 29 项，后者含 4 个父测试。
- Foundation 验证覆盖跨校外键、同一端口未结会话唯一、重复回调、早到事件、同幂等键冲突、独立审批、版本依赖变化、单服务授权、激活保留暂停、回退草稿、核查证据、物理命令不盲重放、撤权和计量周期重置。
- Playwright 原门户回归 3 项通过。Foundation 界面另外使用 Chrome、真实 PostgreSQL 和独立 worker 完成上述人工点击路径。
- Next 构建成功。最终 Windows 构建曾遇到一次生成目录 EPERM，重跑成功。PostgreSQL 子进程曾中断，已从原数据目录恢复并重跑测试。连接池已处理空闲连接断开，日志只记录错误码。
- 新版演示端口为 3015，数据库绑定回环地址，原门户与数据不依赖新演示库。运行与测试方法见 IMPLEMENTATION.md。
